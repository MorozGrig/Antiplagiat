\# Внутренний реестр авторских материалов с контролем уникальности



Веб-приложение для регистрации, хранения и проверки авторских материалов на совпадения с ранее загруженными документами.



\## Возможности проекта



\- Регистрация и авторизация пользователей.

\- Загрузка и хранение авторских материалов.

\- Проверка файлов на точные дубликаты по SHA-256.

\- Поиск текстовых совпадений между материалами.

\- Расчёт процента уникальности.

\- Извлечение текста из PDF, DOCX и TXT.

\- OCR для сканированных PDF с помощью Tesseract.

\- Регистрация изображений и видео с проверкой по хешу.

\- Личный кабинет пользователя.

\- Панель администратора для управления пользователями и материалами.

\- Фоновая обработка документов через Celery.

### PDF-свидетельства

После успешного завершения обработки материала система автоматически формирует PDF-свидетельство о регистрации авторского материала.

Свидетельство содержит:
- Уникальный номер свидетельства.
- Регистрационный номер материала.
- Название материала.
- Сведения об авторе.
- Категорию материала.
- Дату выдачи.
- Процент уникальности на момент проверки.
- Контрольную сумму SHA-256 исходного файла.

PDF-файл сохраняется в S3-совместимом хранилище.

Автор материала может скачать действующее свидетельство из личного кабинета. Администратор также имеет возможность скачать свидетельство.

Для каждого материала создаётся одно свидетельство. Повторная обработка не приводит к созданию дубликата действующего свидетельства.

\## 1. Клонирование проекта



Откройте командную строку и выполните:



```cmd

git clone https://github.com/MorozGrig/Antiplagiat.git

cd Antiplagiat

```



\## 2. Запуск инфраструктуры



В корневой папке проекта выполните:



```cmd

docker compose up -d

```



Команда запустит необходимые сервисы:



| Сервис | Адрес |

|---|---|

| PostgreSQL | localhost:5432 |

| Redis | localhost:6379 |

| S3 API (Silo) | localhost:9000 |

| Консоль Silo | localhost:9001 |

| Elasticsearch | localhost:9200 |



Проверить состояние контейнеров:



```cmd

docker compose ps

```



Дождитесь готовности сервисов перед запуском backend.



\## 3. Настройка переменных окружения



Создайте локальный файл конфигурации:



```cmd

copy .env.example .env

```



Файл `.env` содержит настройки подключения к базе данных, Redis, S3-хранилищу и Elasticsearch.



Для локальной разработки используются тестовые значения из `.env.example`, соответствующие настройкам `docker-compose.yml`.



Не публикуйте `.env` и не используйте тестовые пароли в production-среде.



\## 4. Установка Backend



В корневой папке проекта создайте виртуальное окружение:



```cmd

python -m venv venv

```



Активируйте его:



```cmd

venv\\Scripts\\activate

```



Обновите pip:



```cmd

python -m pip install --upgrade pip

```



Установите зависимости:



```cmd

pip install -r requirements.txt

```



\## 5. Подготовка базы данных



Выполните миграции Alembic:



```cmd

alembic upgrade head

```



Миграции создадут необходимые таблицы и структуру базы данных.



\## 6. Установка Frontend



Откройте второе окно командной строки.



Перейдите в папку frontend:



```cmd

cd Antiplagiat\\frontend

```



Установите зависимости:



```cmd

npm ci

```



\## 7. Установка Tesseract OCR



Для распознавания текста на сканированных PDF установите Tesseract OCR.



В Windows используется путь:



```text

C:\\Program Files\\Tesseract-OCR\\tesseract.exe

```



Установите языковые данные:

\- Russian (rus)

\- English (eng)



В настройках проекта по умолчанию используется:



```env

OCR\_LANGUAGE=rus+eng

```



Важно: текущая реализация OCR содержит путь к Tesseract для Windows. На других операционных системах потребуется адаптировать путь в коде.



\## 8. Запуск приложения



Для полноценной работы проекта необходимо запустить backend, frontend и Celery Worker.



\### Backend



В первом окне командной строки из корневой папки проекта выполните:



```cmd

uvicorn app.main:app --reload

```



Backend будет доступен по адресу:



http://localhost:8000



Документация API:



http://localhost:8000/docs



Проверка состояния:



http://localhost:8000/health



\### Frontend



Во втором окне командной строки из папки `frontend` выполните:



```cmd

npm run dev

```



Frontend будет доступен по адресу:



http://localhost:5173



\### Celery Worker



В третьем окне командной строки из корневой папки проекта активируйте виртуальное окружение и выполните:



```cmd

python -m celery -A app.workers.celery\_app:celery\_app worker --loglevel=info --pool=solo

```



Worker отвечает за фоновую обработку загруженных материалов.



\## 9. Ограничения загрузки



Максимальный размер одного файла:



\*\*10 МБ\*\*



Поддерживаемые форматы:

\- PDF

\- DOCX

\- TXT

\- JPEG

\- PNG

\- MP4

\- MOV

\- AVI

\- MKV



Для PDF, DOCX и TXT выполняется извлечение текста и проверка сходства.



Для изображений и видео используется проверка по хешу без текстового сравнения содержимого.



Точные дубликаты отклоняются при регистрации материала.



\## 10. Запуск тестов



Из корневой папки проекта при активированном виртуальном окружении выполните:



```cmd

python -m pytest -q

```



Для предварительного просмотра найденных тестов:



```cmd

python -m pytest --collect-only -q

```



\## 11. Остановка инфраструктуры



Чтобы остановить контейнеры, выполните:



```cmd

docker compose stop

```



Для повторного запуска:



```cmd

docker compose start

```



Данные PostgreSQL, Redis, Silo и Elasticsearch хранятся в Docker volumes.



Не удаляйте volumes, если хотите сохранить локальные данные.

\## Важные замечания



\- Для полноценной работы приложения должны быть доступны все инфраструктурные сервисы.

\- Для фоновой обработки материалов необходимо запустить Celery Worker.

\- Для OCR необходимо установить Tesseract с языками rus и eng.

\- Elasticsearch используется для индексации текстов.

\- Apache Tika указан в настройках проекта, но текущая реализация обработки материалов его напрямую не использует.

\- Значение `MAX\_FILE\_SIZE` не следует увеличивать без изменения согласованной логики приложения.
