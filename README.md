# Внутренний реестр авторских материалов с контролем уникальности

Веб-приложение для регистрации, хранения и проверки авторских материалов на совпадения с ранее зарегистрированными материалами.

## Возможности проекта

- Регистрация и авторизация пользователей.
- Регистрация авторских материалов с метаданными и уникальным регистрационным номером.
- Проверка точных дубликатов файлов по SHA-256.
- Извлечение текста из PDF, DOCX и TXT.
- OCR сканированных PDF с помощью Tesseract.
- Поиск текстовых совпадений между материалами и расчёт показателя уникальности.
- Регистрация изображений и видео с проверкой по хешу; текстовое сравнение для них не выполняется.
- Личный кабинет пользователя со списком материалов и результатами обработки.
- Автоматическое создание PDF-свидетельства после успешной обработки материала.
- Хранение файлов и PDF-свидетельств в S3-совместимом хранилище.
- Публичная проверка материала без авторизации.
- Панель администратора для управления пользователями и материалами.
- Фоновая обработка материалов через Celery.

## PDF-свидетельства

После успешного завершения обработки материала система автоматически формирует PDF-свидетельство о регистрации материала.

Свидетельство содержит:
- уникальный номер свидетельства;
- регистрационный номер материала;
- название материала;
- сведения об авторе;
- категорию материала;
- дату выдачи;
- показатель уникальности на момент проверки;
- контрольную сумму SHA-256 исходного файла.

PDF-файл сохраняется в S3-совместимом хранилище. Автор может скачать действующее свидетельство из личного кабинета. Для одного материала создаётся одно свидетельство; повторная обработка не создаёт дубликат действующего свидетельства.

## Публичная проверка

На странице `/verify` доступна проверка без входа в аккаунт. Проверить материал можно:
- по номеру свидетельства;
- по регистрационному номеру материала;
- загрузив файл для проверки его SHA-256.

Публичная проверка показывает сведения только о материалах, разрешённых для публичного просмотра и имеющих действительное свидетельство. Загрузка файла для проверки ограничена теми же правилами размера и формата, что и обычная загрузка.

## Установка и запуск

Все команды ниже предназначены для Windows CMD, если не указано иное.

### 1. Клонирование проекта

```cmd
git clone https://github.com/MorozGrig/Antiplagiat.git
cd Antiplagiat
```

### 2. Запуск инфраструктуры

В корневой папке проекта выполните:

```cmd
docker compose up -d
```

Команда запускает необходимые сервисы:

| Сервис | Адрес |
|---|---|
| PostgreSQL | localhost:5432 |
| Redis | localhost:6379 |
| S3 API (Silo) | localhost:9000 |
| Консоль Silo | localhost:9001 |
| Elasticsearch | localhost:9200 |

Проверить состояние контейнеров:

```cmd
docker compose ps
```

Дождитесь готовности сервисов перед запуском backend.

### 3. Настройка переменных окружения

Создайте локальный файл конфигурации:

```cmd
copy .env.example .env
```

Проверьте настройки подключения к PostgreSQL, Redis, S3-хранилищу и Elasticsearch в `.env`. Значения должны соответствовать вашей локальной конфигурации Docker Compose.

Не публикуйте `.env` и не используйте тестовые пароли в production-среде.

### 4. Установка Backend

В корневой папке проекта создайте виртуальное окружение:

```cmd
python -m venv venv
```

Активируйте его:

```cmd
venv\Scripts\activate
```

Обновите pip и установите зависимости:

```cmd
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Подготовка базы данных

Выполните миграции Alembic:

```cmd
alembic upgrade head
```

### 6. Установка Frontend

Откройте второе окно CMD и перейдите в папку frontend:

```cmd
cd Antiplagiat\frontend
```

Установите зависимости:

```cmd
npm ci
```

### 7. Установка Tesseract OCR

Для распознавания текста на сканированных PDF установите Tesseract OCR и языковые данные:
- Russian (`rus`)
- English (`eng`)

В текущей конфигурации Windows используется путь:

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

Языки OCR задаются настройкой `OCR_LANGUAGE` (обычно `rus+eng`). Если Tesseract установлен в другом месте или проект запускается на другой операционной системе, путь к исполняемому файлу необходимо настроить соответствующим образом.

### 8. Запуск приложения

Для полноценной работы необходимо запустить backend, frontend и Celery Worker.

**Backend**

В первом окне CMD из корневой папки проекта:

```cmd
uvicorn app.main:app --reload
```

Адрес backend: http://localhost:8000

Документация API: http://localhost:8000/docs

Проверка состояния: http://localhost:8000/health

**Frontend**

Во втором окне CMD из папки `frontend`:

```cmd
npm run dev
```

Frontend будет доступен по адресу http://localhost:5173

**Celery Worker**

В третьем окне CMD из корневой папки проекта с активированным виртуальным окружением:

```cmd
python -m celery -A app.workers.celery_app worker --loglevel=info --pool=solo
```

Worker выполняет фоновую обработку загруженных материалов и участвует в последующей генерации PDF-свидетельств.

## Ограничения загрузки и проверки

Максимальный размер одного файла — **10 МБ**.

Поддерживаемые форматы:
- PDF
- DOCX
- TXT
- JPEG
- PNG
- MP4
- MOV
- AVI
- MKV

Для PDF, DOCX и TXT выполняется извлечение текста и текстовая проверка сходства. Для сканированных PDF может применяться OCR.

Для изображений и видео выполняется проверка по хешу без текстового сравнения содержимого.

При загрузке проверяются размер, тип и содержимое файла, а также метаданные материала. Точные дубликаты по SHA-256 отклоняются при регистрации.

Публичная проверка загруженного файла сопоставляет его SHA-256 с доступными для публичной проверки зарегистрированными материалами. Она не выполняет полноценное текстовое сравнение нового файла со всеми материалами реестра.

## Важные замечания

- Для полноценной работы приложения должны быть доступны инфраструктурные сервисы.
- Для фоновой обработки материалов необходимо запустить Celery Worker.
- Для OCR необходимо установить Tesseract с языками `rus` и `eng`.
- Elasticsearch используется компонентами поиска и индексации проекта.
- Apache Tika может присутствовать в конфигурации, но текущая реализация обработки материалов напрямую его не использует.
- Не увеличивайте `MAX_FILE_SIZE` без согласованного изменения ограничений и проверок приложения.
- Показатель уникальности является результатом автоматизированного сравнения в рамках реализованных алгоритмов. Система не гарантирует обнаружение всех возможных заимствований.
- PDF-свидетельство подтверждает наличие записи в реестре и результат проверки на момент выдачи. Оно не является государственным документом, удостоверяющим авторские права; юридическая оценка его доказательственного значения зависит от обстоятельств и применимого законодательства.
